# Portfolio Website - Rishabh Shukla

A modern, Spotify-themed portfolio website featuring a sleek design with green (#1DB954) and black color scheme.

## Features

- **Spotify-inspired Design**: Green and black theme matching Spotify's aesthetic
- **Responsive Layout**: Works seamlessly on desktop, tablet, and mobile devices
- **Smooth Animations**: Interactive elements with smooth transitions
- **Modern UI/UX**: Clean, professional design with excellent user experience
- **Hero Section**: Eye-catching introduction with circular profile image and 3D animations
- **3D Profile Animation**: Rotating rings, orbiting tech icons, and floating particles around profile image
- **Fixed Navbar**: Easy navigation with smooth scrolling

## Structure

### Current Pages
- **Home/Intro Page**: Features hero section with introduction, call-to-action buttons, and animated visualizations

### Navigation
- About
- Skills

- Contact
- Resume button (highlighted)

## Getting Started

1. **Add Your Profile Image**: Place your profile photo in the project folder and name it `profile.jpg` (or update the image path in `index.html` line 82)
2. Open `index.html` in your web browser
3. No build process required - it's a static website!

## Customization

### Update Resume Link
In `script.js`, find the resume button handler and update:
```javascript
window.open('path-to-your-resume.pdf', '_blank');
```

### Update Contact Links
Modify the "Let's Connect" button in `index.html` to link to your LinkedIn, email, or contact form.

### Colors
The Spotify theme colors are defined in `styles.css`:
- Primary Green: `#1DB954`
- Black: `#121212`
- Dark Gray: `#1a1a1a`
